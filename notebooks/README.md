# Starter notebooks

Two Colab-ready notebooks land here at acceptance:

- `competitor_starter.ipynb` — participant entry point: bundle loading, v1 checkpoint loading and inference, track-formatted submission writing, local scoring.
- `uncgpt_e2e_demo.ipynb` — end-to-end pipeline demo: persona issuance → conversation generation → semantic gate → scorer invocation.

Both run on the free Colab tier (T4 GPU is enough for inference). Until then, the in-browser WebGPU demo at [`Reza2kn/uncgpt-69-hybrid-demo`](https://huggingface.co/spaces/Reza2kn/uncgpt-69-hybrid-demo) is the quickest way to feel what the reference baseline does.
